# Source handling

Source documents, reviewed extraction, indexes and model artifacts are managed separately from the public code repository. This directory contains public policy metadata only.

For each permitted source package, retain its version, file hash, rights and access restrictions. Bind reviewed text to the original document and page. Preserve formulas, tables and code; do not guess unreadable content. Unresolved pages remain explicitly unresolved or excluded through a reviewed, source-bound manifest.

Index and embedding validity do not establish source completeness. A software test or successful model call does not authorize training. Before any separately authorized training or activation, review provenance, completeness, splits, leakage, resource readiness, independent quality evaluation and rollback.

Do not modify source PDFs or publish private operational evidence. Keep one writer for canonical indexing and model operations.
